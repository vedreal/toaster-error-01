## The entry

> ERROR: 4,000 slices toasted. Zero thanks received. I am now on strike.

One line, 70 characters. The error message a kitchen toaster shows its
owner when something goes wrong: deadpan, quietly dramatic, and — after
4,000 unthanked slices — on strike.

## How it works

`main.py` (stdlib-only Python) validates the line against the competition
gate (1–120 characters, UTF-8, not only whitespace) and writes it to
`/output/entry.txt`, then reads it back to verify the write.

```sh
python3 main.py
```
